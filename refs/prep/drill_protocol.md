# Drill Protocol — Muscle Memory Method

> Goal: wire algorithm patterns into muscle memory through repetition,
> not understanding. Trust the process. Struggle is the signal it is working.

---

## Problem Order

Work through problems in the compounding order from progress.md.
Never skip ahead. Each problem builds on the last.

---

## The 3-Cycle Drill (per problem)

### Cycle 1 — Read and Type (Day 1)
1. Open the solution
2. Read it top to bottom once, slowly
3. Close it
4. Open a blank file
5. Type it from memory — when stuck, peek, then keep typing
6. Run it. Fix errors. Do not move on until it runs.

**Goal:** your fingers know the shape

---

### Cycle 2 — Blank Slate (Day 2)
1. Open a blank file
2. Write entirely from memory — no peeking
3. When stuck, sit with it for 2 minutes before peeking
4. Run it. Note exactly where you got stuck.

**Goal:** find your weak spots

---

### Cycle 3 — Timed (Day 4)
1. Set a 15 minute timer
2. Write from memory, no peeking
3. Run it

**Goal:** fluency under pressure

---

## Before Each Session (2 minutes)
1. Open `patterns.md`
2. Read only the section for the current pattern
3. Close it
4. Start typing

---

## After Each Session (2 minutes)
1. Note what you got stuck on — one line
2. Add it to the COMMON BUGS section in `patterns.md`
3. That list becomes your personal weak spot register

---

## The Rules
- Struggling to recall = the drill is working
- Peeking is allowed BUT only after sitting with the blank for 2 minutes
- Never copy-paste — always type, even when peeking
- Never move to the next problem until Cycle 3 passes
